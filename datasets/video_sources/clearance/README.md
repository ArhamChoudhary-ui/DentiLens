# Clearance packet

Generate a private owner worksheet and unsent outreach drafts with
`scripts/audit_source_clearance.py datasets/video_sources /path/to/new/local/packet`.
The source opportunity inventory is public metadata. Keep consent documents,
contact details, rights approvals, full paths, and private worksheets local.

Review eight intended uses independently. `retain` covers crops,
annotations and benchmark output. Older grants that omit it require a
separate recorded approval before creating new derived data. Commercial
scope remains separately recorded when applicable.
