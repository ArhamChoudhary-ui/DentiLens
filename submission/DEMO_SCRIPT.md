# Track 4 demo script

**Target 2 minutes 30 seconds.** Use a manifest video that the team is
authorized to show. Keep the source and generated timestamps visible
and load the prepared JSON for instant review. Label approximate
window boundaries and highlight scores as model output.

| Time | Show | Say |
| --- | --- | --- |
| 0:00–0:20 | Source first-person MP4 and the team title | “DentiLens XR turns first-person video into searchable action intervals and a short replay of useful moments.” |
| 0:20–0:50 | Run the offline CLI against the shorter manifest sample | “The command validates the original video and scores sampled frames. The manifest selects the model path and every segment keeps its source timestamp.” |
| 0:50–1:20 | Show window scores and then the six-field JSON | “The verb and noun scores are paired using combinations observed in training. Overlapping same-action windows are reduced. These are temporal estimates.” |
| 1:20–1:50 | Play the original selected MP4, show retained percentage | “Selection rewards distinct actions and keeps chronological, non-overlapping source footage. This 29.51-second sample retained four seconds.” |
| 1:50–2:15 | Run the checker and show the benchmark table | “The local contract checker verifies the sample. The official scoring and full batch still need the complete organizer inputs.” |
| 2:15–2:30 | Show XR review flow and scope | “The next XR step is timestamped review. A real headset deployment and clinical action validation remain future work.” |

Record at 1080p when available. Keep the demo below three minutes. Never
present an abstention as a class prediction or the sample diagnostics as
the organizer score. Keep clips local until media-sharing rights are confirmed.
